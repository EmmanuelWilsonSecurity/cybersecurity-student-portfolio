# COS 106 Student Portfolio Website

A responsive multi-page student portfolio and academic management website built with plain HTML5, CSS3 and JavaScript.

## Pages
- `index.html` — Homepage
- `about.html` — Biography, education, skills, interests and academic table
- `projects.html` — Three sample projects and embedded sample video
- `planner.html` — Interactive task planner (add, complete, delete; saves in browser localStorage)
- `contact.html` — Contact form with required-field, email and digit-only phone validation

## Run locally
1. Open this folder in Visual Studio Code.
2. Install the Live Server extension (optional but recommended).
3. Right-click `index.html` and select **Open with Live Server**.

You can also open `index.html` directly in a browser.

## Before submission
Replace all placeholder text (`Your Name`, course, institution, contact details, dates) with accurate information. Replace `images/profile-placeholder.svg` with your own suitable photo (update the image references if you change its filename). Replace sample projects and video with your own work if required.

The contact form currently validates in the browser only; it does not send messages to an email address or server. The video is loaded from an external sample media URL and therefore requires an internet connection.
